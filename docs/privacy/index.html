Политика конфиденциальности приложения «Тишина»

Приложение «Тишина» (далее — «Приложение») не собирает, не передаёт и не хранит на удалённых серверах никакие персональные или аудиоданные. Этот документ объясняет, как именно Приложение работает с данными на устройстве пользователя.

1. Какие данные обрабатывает Приложение

Приложение работает локально на устройстве и обрабатывает исключительно технические данные, необходимые для измерения уровня окружающего шума:

  • Текущие отсчёты с микрофона — обрабатываются в оперативной памяти как поток PCM-данных и используются только для вычисления уровня звукового давления в дБ. Аудио не записывается в файлы, не сохраняется в постоянную память и не передаётся за пределы устройства.
  • Агрегированные результаты измерений (среднее, минимум, максимум, длительность, метка времени, опциональное название и заметка), которые пользователь явно сохранил в историю замеров. Эти данные хранятся в приватном хранилище приложения и доступны только самому приложению.
  • Калибровочное смещение в дБ — пользовательская настройка, сохраняется в DataStore Preferences в приватном хранилище.

2. Использование микрофона

Приложение запрашивает разрешение RECORD_AUDIO. Микрофон активен только пока пользователь явно запустил измерение в Приложении. Аудиопоток не сохраняется в виде файла, не транскрибируется, не отправляется на удалённые серверы и не используется ни в какой форме, кроме вычисления уровня шума в реальном времени.

3. Хранение данных

Все сохранённые измерения и пользовательские настройки хранятся только в приватном хранилище приложения на устройстве (Android internal storage, изолированном песочницей приложения). Эти данные не синхронизируются в облако и не покидают устройство автоматически.

Удаление приложения через стандартный механизм Android приводит к полному удалению всех данных Приложения с устройства.

4. Передача данных третьим лицам

Приложение не содержит сторонних SDK для аналитики, рекламы, A/B-тестирования или сбора отчётов о сбоях. Приложение не имеет сетевого доступа и не разрешает в манифесте permission INTERNET.

Никакие данные не передаются третьим лицам, рекламным сетям, брокерам данных, государственным органам (за исключением случаев, прямо предусмотренных применимым законодательством), или в исследовательских целях.

5. Экспорт данных пользователем

Если пользователь явно инициирует экспорт истории измерений в CSV-файл, открывается системный диалог выбора места сохранения (Storage Access Framework). Приложение записывает CSV-файл в выбранную пользователем папку. После сохранения файл управляется пользователем — Приложение не имеет к нему автоматического доступа и не отслеживает дальнейшее использование.

6. Дети

Приложение не предназначено целенаправленно для детей младше 13 лет и не запрашивает информацию о возрасте пользователя. Приложение не собирает данные ни от каких пользователей, поэтому требования COPPA / GDPR-K по обработке детских данных не применяются.

7. Изменения политики

При существенных изменениях этой политики обновлённая редакция публикуется по тому же URL вместе с новой датой в начале документа. История изменений доступна в git-репозитории: github.com/dnovichkov/tishina-android.

Вопросы и обращения по политике конфиденциальности — через GitHub Issues: github.com/dnovichkov/tishina-android/issues.

Privacy Policy — Tisha

The Tisha app (the “App”) does not collect, transmit, or store any personal data or audio recordings on remote servers. This document explains how the App handles data on the user’s device.

1. Data processed by the App

The App runs locally on the device and processes only the technical data required to measure ambient noise level:

  • Live microphone samples — processed in RAM as a stream of PCM audio and used only to compute the sound pressure level in dB. Audio is never written to a file, never persisted, and never sent off the device.
  • Aggregated measurement results (average, minimum, maximum, duration, timestamp, optional title and note) that the user explicitly saved to history. These are stored in the App’s private storage and accessible only to the App itself.
  • Calibration offset in dB — a user-controlled setting stored in DataStore Preferences inside private storage.

2. Microphone usage

The App requests the RECORD_AUDIO permission. The microphone is active only while the user has explicitly started a measurement inside the App. The audio stream is not saved to a file, not transcribed, not uploaded to any remote server, and not used for any purpose other than real-time noise-level measurement.

3. Data storage

All saved measurements and user settings are stored only in the App’s private storage on the device (Android internal storage, isolated by the application sandbox). This data is not synced to the cloud and does not leave the device automatically.

Uninstalling the App through Android’s standard mechanism fully deletes all App data from the device.

4. Third-party data sharing

The App contains no third-party SDKs for analytics, advertising, A/B testing, or crash reporting. The App has no network access and does not declare the INTERNET permission in its manifest.

No data is shared with third parties, advertising networks, data brokers, government agencies (except where required by applicable law), or research projects.

5. User-initiated data export

If the user explicitly triggers the CSV export feature, the system file picker (Storage Access Framework) opens so the user can choose the destination folder. The App writes the CSV file to the chosen location. After saving, the file is fully under the user’s control — the App has no automatic access to it and does not track its further use.

6. Children

The App is not specifically directed at children under 13 and does not request the user’s age. The App does not collect data from any user, so COPPA / GDPR-K requirements on children’s data processing do not apply.

7. Changes to this policy

Material changes to this policy are published at the same URL together with a new effective date at the top of the document. Change history is available in the git repository: github.com/dnovichkov/tishina-android.

8. Contact

Questions about this Privacy Policy should be raised via GitHub Issues: github.com/dnovichkov/tishina-android/issues.
