## Декларация разрешений (для модератора)

Полные обоснования — в `../permissions-rationale.md`. Короткий пересказ для поля
«Комментарий для модератора» в Console:

> `android.permission.RECORD_AUDIO` — единственное запрашиваемое разрешение.
> Используется только во время активного измерения уровня шума на экране «Измерение».
> Аудиопоток обрабатывается в оперативной памяти и моментально отбрасывается; никакие
> аудиофайлы не сохраняются и не передаются. Приложение работает полностью офлайн —
> разрешения `INTERNET` нет в release-манифесте.

## Что отвечать на типовые вопросы модерации RuStore

1. **«Какие данные собирает приложение?»** — никаких. Нет сетевого кода, нет SDK
   аналитики/рекламы. См. `../data-safety.md`.
2. **«Зачем нужен микрофон?»** — для замера уровня окружающего шума. См. выше + полный
   разбор в `../permissions-rationale.md`.
3. **«Это обёртка над сайтом?»** — нет. Нативный Android-app на Kotlin + Jetpack
   Compose; никакого WebView в production-манифесте.
4. **«Есть ли реклама и встроенные покупки?»** — нет ни того, ни другого. Никогда не
   будет (зафиксировано в Privacy Policy и README).
